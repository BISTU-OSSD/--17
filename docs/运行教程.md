# 十二星座运势查询系统 使用文档
## 一、项目结构分工
1. data.py 【feature/data分支】：数据源模块，存放十二星座全部文案资料
2. judge.py 【feature/judge分支】：输入校验、星座判定核心逻辑
3. show.py 【feature/show分支】：控制台彩色UI、排版美化输出
4. main.py 【feature/main-doc分支】：项目总调度入口

## 二、运行步骤
1. 将四个py文件放在同一个文件夹内
2. 打开终端，执行运行命令：
`python main.py`
3. 依次按照提示输入：出生月份、出生具体日期
4. 程序自动完成：输入校验 → 星座计算 → 彩色排版输出完整运势
5. 非法输入会红色弹窗提示错误信息

## 三、分支合并说明
各成员在对应功能分支开发完成后，提交Pull Request，审核通过合并至main主干分支，完成项目整体整合。
